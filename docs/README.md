# Documentation

## diagrams/

- [class_diagram.mmd](diagrams/class_diagram.mmd): Mermaid class diagram of the Python scanner.
- [object_diagram.md](diagrams/object_diagram.md): object diagram of one assembled graph snapshot.
- [sequence_diagram.mmd](diagrams/sequence_diagram.mmd): Mermaid sequence diagram of one `python -m vulnmapper` run.
- [UML_DIAGRAMS.md](diagrams/UML_DIAGRAMS.md): class, object and sequence diagrams in Mermaid, grouped by use case.
- [DIAGRAM_REFERENCE.md](diagrams/DIAGRAM_REFERENCE.md): catalogue of classes, attributes and relationships for drawing the diagrams.
- [UML_DIAGRAMS.drawio](diagrams/UML_DIAGRAMS.drawio): draw.io version of the UML diagrams.
- [UML_CLASS_OVERVIEW.drawio](diagrams/UML_CLASS_OVERVIEW.drawio): draw.io class overview.

## archive/

The archive holds documents from earlier stages of the project. They are kept
for reference and are not maintained, so paths and details in them may be out
of date.

- [CODE_UNDERSTANDING.md](archive/CODE_UNDERSTANDING.md): walkthrough of the codebase as it was before the reorganization.
- [MERGE_VERIFICATION_REPORT.md](archive/MERGE_VERIFICATION_REPORT.md): report on porting the earlier Vite GUI into the Next.js app.
- [REFACTOR_NOTES.md](archive/REFACTOR_NOTES.md): decisions log of the scanner consolidation refactor.
- [comware_verification_report.txt](archive/comware_verification_report.txt): output of the HP Comware switch verification script.
- [vulnmapper-README-old.md](archive/vulnmapper-README-old.md): the scanner's earlier README.
